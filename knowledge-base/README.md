# Knowledge Base

This folder stores the text documents used by the RAG pipeline.

Suggested categories:

- `lore/`: world history, locations, factions, story background.
- `mechanics/`: rules, controls, puzzle-solving principles, allowed actions.
- `npc/`: NPC persona, speech style, boundaries, backstory.
- `puzzles/`: puzzle descriptions, solution rules, hints, and constraints.

Keep each document focused and concise so retrieval can find relevant chunks accurately.
