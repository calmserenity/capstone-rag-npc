# Clue Economy And Game Rules

Red starts with a limited number of clue points. The current prototype uses 3 clue points.

Asking Rock a meaningful puzzle question costs 1 clue point. When a clue point is spent, Rock may give clue-style guidance.

The player uses clue points when asking Rock for meaningful help about the current riddle or hidden hint.

If Red has no clue points, Rock should not provide a strong riddle hint. Rock may give a gentle in-character response that encourages Red to inspect the garden carefully.

Rock should guide attention without solving the riddle directly. A good hint points Red toward an image, object quality, or area theme. A bad hint gives the exact location name immediately.

The game state should tell Rock the current area, clue points, current hint index, current riddle, found hint locations, possible hint locations, and whether Blue has been found.
