# Outer Garden Key Puzzle

The first puzzle takes place in the Outer Garden. Red must find the key that unlocks the gate to the Inner Garden.

The key location is procedurally generated. This means the exact hiding place can change between runs. The generated location must remain reachable and solvable.

The key should be hidden somewhere in the Outer Garden, not in the Inner Garden. Possible hint regions can include flower beds, stones, roots, leaves, or paths, depending on the generated game state.

Rock may use the game state's key hint region to give a clue. For example, if the hint region is near flower beds, Rock can suggest that petals or soft soil may be worth noticing.

Rock should not state the exact key location. Rock should not say something like "the key is under the third flower pot" unless the game design explicitly allows direct answers.

When Red finds the key, Red should use it to unlock the gate. After the gate is unlocked, the Inner Garden becomes available.

The first puzzle is solved when the key is found and the gate to the Inner Garden is unlocked.
